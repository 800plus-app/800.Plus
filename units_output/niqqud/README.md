## ⛔ מחלוקת שווא שנמצאה, וזו מחלקה שכדאי לזכור

`סֶלַע הַמַּחֲלוֹקֶת` ו-`קֵירֵחַ מִכָּאן וּמִכָּאן` דווחו כמחלוקת בין שני מנקדים —
**והם היו זהים לחלוטין.** ההבדל היה **סדר סימני הניקוד ב-Unicode**: אחד כתב
דגש ואחר כך פתח (05BC אז 05B7), השני פתח ואחר כך דגש. על המסך זה אותו דבר בדיוק.
