# רתמות שיניים · `tests/teeth/`

⛔ **הקבצים כאן אינם בדיקות.** ‏`tests/run.js` סורק `*.test.js` בתיקייה העליונה
בלבד, ולכן הם אינם נאספים לחבילה · והם לא אמורים להיאסף.

⭐ **מה הם כן:** כל רתמה בונה עותק של הקוד בתיקייה זמנית, **שוברת בו דבר אחד
בכוונה**, ומריצה את השער מולו · כדי להראות שהשער **נופל**.

> **שער ירוק שלא ראית נופל אינו עדות.** זה קרה בפרויקט הזה שלוש פעמים.

## למה הם בעץ ולא בסקרצ'פד

⛔ **טבלת מוטציות שאי אפשר להריץ מחדש אינה עדות.** דוח עם `EXIT=1` שאיש אינו
יכול לשחזר הוא הצהרה, לא מדידה. הקבצים כאן הועברו לעץ בדיוק מהסיבה הזאת.

```
node tests/teeth/<שם>.teeth.js <מוטציה>
```

## ⛔ שני כללים שנלמדו כאן, בדם

1. **הרתמה חייבת להיות עצמאית.** ‏`78` נשען בעבר על תמונת־מצב של `app.js`
   שישבה בסקרצ'פד · ולכן הוא לא רץ בכלל אצל מי שאין לו אותה. המוטציה `old`
   נבנית עכשיו **מהמקור החי**.
2. **מוטציה שנופלת אינה בהכרח מוטציה שעבדה.** בדוק שהיא הפילה את **הבדיקה
   שהתכוונת לה**, ולא אחרת. קרה כאן שלוש פעמים.
