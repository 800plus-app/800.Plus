## שלוש ההמלצות

### 1. Remotion · סקילים רשמיים ⭐

```
npx skills add remotion-dev/skills
```

12 סקילים רשמיים מ-remotion.dev. וידאו פרוגרמטי מ-React. **126,000+ התקנות · הסקיל הרביעי הכי מותקן בעולם.**

הרלוונטיים: `remotion-markup` (אנימציה, טיפוגרפיה, תזמון) · `remotion-render` · `remotion-captions` (כתוביות) · `remotion-create` · `remotion-studio`.

**הפער שנסגר:** הסטוריז שלנו הם PNG סטטיים, והפרסומת היא 6 תמונות עם fade. אינסטגרם מעדיף וידאו. Remotion מייצר 9:16 אנכי ישירות.

**כתוביות:** רוב הצפייה ברשתות היא בהשתקה. `remotion-captions` הוא הסיבה השנייה להתקין.

**⚠ רישיון:** חינם ליחידים ולחברות **עד שלושה אנשים**, כולל שימוש מסחרי. מארבעה ומעלה נדרש רישיון בתשלום. חגי סולו, ולכן חינם — אבל אם 800+ יגדל לצוות, זו עלות שצריך לזכור.

### 2. GSAP · סקילים רשמיים של GreenSock

```
npx skills add https://github.com/greensock/gsap-skills
```

**13.1k כוכבים · MIT · רשמי.** 8 סקילים: gsap-core · gsap-timeline · gsap-scrolltrigger · gsap-plugins · gsap-utils · gsap-react · gsap-performance · gsap-frameworks.

**למה זה מתחבר ישירות לצינור הקיים:** אנחנו כבר מרנדרים HTML דרך Edge ומרכיבים ב-ffmpeg (`רנדר.ps1`, `סרטונים/render.ps1`). GSAP מאפשר לרנדר פריימים של אנימציה אמיתית במקום ביטים סטטיים — אותו סקריפט, תוצר אחר לגמרי.

### 3. jiji262/claude-design-skill · משמעת אנטי-סלופ

```
npx skills add jiji262/claude-design-skill -g
```

**170 כוכבים · MIT.** מותאם ממערכת העיצוב הפנימית של Claude.ai.

מה שיש בו: אימות עובדות לפני עיצוב · **כללי anti-slop מפורשים נגד הסימנים שמסגירים עיצוב שנוצר ב-AI** · תבניות לפוסטרים, מצגות, פרוטוטייפים ואנימציות.

**למה דווקא הוא:** זה בדיוק הלקח של המקף הארוך, אבל בשכבה הוויזואלית. אותו סוג של סימן מזהה קיים גם בעיצוב.
