המלא להעתקה, מה לבדוק לפני, ולמה הפוסט בנוי כך.

**עודכן 20.8.2026 · 14 יום למועד ספטמבר.**

⚠ **הספירה מתיישנת כל לילה.** `date` לפני כל נכס תלוי-תאריך, ורינדור מחדש
ביום ההעלאה. ב-16.8 יצא פוסט עם `19` שחושב ליום הקודם, ונתפס לפני הפרסום,
וב-19.8 שקופית שרונדרה ב-17.8 הכריזה `17` כשהנכון היה `15`.
