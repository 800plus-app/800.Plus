**התיקייה הזו אינה מחזיקה קבצי עיצוב, ובכוונה.** העיצוב חי ב-`index.html` עצמו — אין Figma, אין קובץ מותג נפרד, ואין מערכת עיצוב חיצונית. קובץ נפרד היה מתיישן מול הקוד תוך שבוע והופך למקור שקרי.

מה שיש כאן הוא **הפניה מדויקת למקום שבו העיצוב באמת נמצא**, כדי שמעצב או כלי AI יוכלו לעבוד לפי הדבר האמיתי.

## הפלטה · `index.html`, בלוק `:root`

```css
--paper:#f6f1e7      /* רקע — נייר חם, לא לבן */
--paper-deep:#efe7d6 /* רקע משני */
--card:#fffdf8       /* כרטיסים */
--ink:#2c2620        /* טקסט ראשי — חום-שחור, לא שחור */
--ink-soft:#736a5c   /* טקסט משני */
--gold:#c9962f       /* הצבע המוביל · מספרים, הדגשות, המותג */
--accent:#b5482e     /* חלודה · טעות, אזהרה, חולשה */
--accent-deep:#8f3620
--green:#4e7d4e      /* הצלחה */
--line:#e3d8c4       /* קווי הפרדה */
--shadow:0 10px 30px -14px rgba(90,60,20,.4)
```

> `--ink-soft` היה `#7d7365` ותוקן. ביחס לרקע הוא נתן 4.13:1 — נמוך מ-AA ב-0.37. **אל תבהיר אותו בחזרה.** כל צבע חדש חייב לעמוד ב-4.5:1 מול הרקע שעליו הוא יושב.

## הכלל שמסביר את הפלטה

**נייר חם ולא לבן · דיו חום ולא שחור · זהב למה שנמדד וחלודה למה שנחלש.** אפליקציית לימוד שנפתחת בשעות הלילה — מסך לבן בוהק הוא הדבר הראשון שגורם לסגור אותה.

בסרטון ובסטוריז הפלטה מתהפכת לרקע כהה (`ad.html`, בלוק `:root`) אבל הזהב והחלודה זהים — זה מה שמחזיק את הזהות בין האתר לפרסום.
