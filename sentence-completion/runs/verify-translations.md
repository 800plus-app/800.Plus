### פריטים שבהם התרגום העברי לא יכול להבחין בין התשובה למסיח (5)
`g` נותן לתשובה ולמסיח פירוש **זהה**, וה-`t` מדגיש בדיוק את המילה המשותפת:
- `adv4.json#9` preserve = conserve = לשמר → `t`: **לשמר**
- `mid2.json#4` traffic = movement = תנועה → `t`: **התנועה**
- `mid2.json#5` border = limit = גבול → `t`: **הגבול**
- `mid2.json#11` confirm = approve = לאשר → `t`: **לאשר**
- `mid4.json#11` subject = topic = theme = נושא (שלושה זהים!) → `t`: **מקצוע**. כאן ה-`t` דווקא נכון לפי `e` ("מקצוע לימוד"), אבל ה-`g` הופך את הפריט לבלתי פתיר.

### תקלות ב-`g` שמכשילות את היגיון הפריט (לא ב-`t`, אבל מגיעות לאותו מסך)
- `adv3.json#1` + `v2.json#5`: **treat = להתייחס; לפנק**. שני הפריטים רפואיים, וכל היגיון הפסילה של המסיח דורש "לטפל". ב-v2#5 זה קריטי: הלומד צריך לפסול treat כי הוא רק מקל על הסימפטומים.
- `mid2.json#12`: **greet = לקבל פנים** — אינו עברית. → "לקדם בברכה".
- `aca4.json#11`: **enclose = לצרף** — זו המשמעות במכתבים; כאן דרוש "להקיף/לסגור מכל הצדדים", כפי ש-`e` אכן מסביר.
- פירושים בזמן עבר או בשם עצם במקום שם פועל: `gather = אסף` (aca2#4, adv4#3), `descend = ירד` (adv4#2), `scrutinize = בחן` (aca2#7), `block = חסימה` (aca.json#2, adv3#12), `knot = קשר` / `twist = סיבוב` (adv4#6), `despair = להתייאש` (adv5#5), `audit = ביקורת` (aca2#7), `measure = אמצעי; למדוד` (mid4#9).
