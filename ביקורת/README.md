# ביקורת · איך המערכת עובדת

**המטרה:** סשן שעובד אינו יכול לבקר את עצמו. הוא מכיר את ההנחות שלו, ולכן הוא עיוור
בדיוק לנקודות שבהן הן שגויות. **סשן נפרד, בהקשר נקי, בודק מה נעשה.**

⭐ זה לא רעיון שלנו — זה הדפוס שהמחקר קורא לו **maker-checker split**: מי שבנה לא
בודק, והבודק מגיע בלי לירוש את ההנחות של הבונה.

⚠ **מה בגיט ומה לא, ולמה.** `יומן-עבודה.md` **כן** — הוא נקודת התיאום בין סשנים,
ובלעדיו סשן בעץ עבודה אחר לא יראה מה נעשה. `דוחות/` ו-`משימות/` **לא** — שניהם מפרטים
באגים ולעיתים נוגעים במשתמש מסוים, והריפו ציבורי.
⛔ ומכאן נגזרת חובה על היומן עצמו: **אין בו מיילים, אין `user_id`, ואין סודות.**

⛔ **ואיך נמנעת התנגשות ב-`משימות/`:** שם הקובץ נגמר ב-8 התווים הראשונים של **מזהה
הסשן**, שהסשן גוזר מנתיב ה-scratchpad של עצמו. אין קובץ אינדקס משותף — רשימת התיקייה
היא האינדקס, כי כל קובץ מרכז הוא בדיוק נקודת ההתנגשות שהמבנה בא למנוע.
הפירוט: [`משימות/README.md`](משימות/README.md).

## הזרימה

```
סשן עובד  →  משימה נסגרה   →  שורה ב-יומן-עבודה.md      →  קומיט
          →  משימה נשארה   →  שורה ב-משימות/<המזהה שלו>.md
                                        ↓
סשן מבקר  →  קורא את היומן  →  מוצא שורות ⬜  →  בודק  →  דוח + מסמן ✅
                                        ↓
חגי       →  חוזר לסשן      →  "תסיים את המשימות"  →  הסשן קורא את הקובץ שלו
```

⭐ **ומה שהמבקר עושה עם `משימות/`:** קורא, ולא כותב לקובץ של אף אחד אחר. משימה פתוחה
בקובץ של סשן אחר היא **הקשר** — היא מראה לו איפה הבונה עצמו יודע שלא סיים.

יורש גם את ההנחות — וזה מבטל את כל התועלת.

## ⛔ ומה שהמחקר אומר, ומעצב את הפרומט

**הכשל של מבקרים אוטומטיים אינו החמצה — הוא רעש.** מודל שפה ממוקסם ל**סבירות**, לא
לנכונות, ולכן הוא מייצר ממצאים שנשמעים משכנעים ואינם נכונים.

⭐ **הדוגמה שסוגרת את הדיון:** `curl` **סגר את תוכנית הבאונטי שלו לצמיתות** אחרי
שדוחות שנוצרו ב-AI הורידו את שיעור הממצאים המאומתים מתחת ל-5%. המתחזקים תיארו את זה
כ"מתקפת מנע".

**מכאן שני עקרונות שהפרומט בנוי עליהם:**

1. ⛔ **פרומט מקסימליסטי גרוע מקריטריונים מכוילים.** המחקר מנסח את זה חד: *"סט
   קריטריונים מכויל עם שיעור התראות-שווא מתחת ל-15% שווה פי עשרה מפרומט מקסימליסטי."*
   לכן הפרומט **רחב בכיסוי** אך **קשוח בשאלה מה נחשב ממצא**.
2. ⛔ **מסגור יריב לבדו אינו מספיק.** המבקר חייב **להריץ** ולא רק לקרוא. אימות
   אמפירי תופס דברים שביקורת בקריאה מפספסת.

**המספר שהמערכת מכוילת אליו: פחות מ-15% התראות שווא.** גישה דומה בספרות הורידה
88.6% מהתראות השווא במחיר 3.1% מהכיסוי — זה היחס שאנחנו רוצים.

## מה נמדד עליה

| | |
|---|---|
**שיעור התראות שווא** | היעד: < 15%. כל דוח מדווח כמה ממצאים נפלו באימות |
**זמן לסבב** | 30–60 דקות. מעבר לזה איכות הביקורת צונחת |
**כיסוי** | כל שורה ⬜ ביומן נבדקה או נדחתה במפורש, לא נשמטה |
