## 1 · מפתחות

```bash
bash scripts/vapid_keys.sh
```

מדפיס למסך ואינו כותב לקובץ — ⛔ **מפתח פרטי שנכתב לקובץ הוא מפתח פרטי ששוכחים
למחוק, ואז הוא נכנס לגיבוי הבא.**

| מה | לאן |
|---|---|
`VAPID_PUBLIC` | `config.js`, שורת `window.VAPID_PUBLIC`. **פומבי מעצם הגדרתו** |
`VAPID_PRIVATE` | Supabase → Edge Functions → Secrets. **לא לקובץ, לא לצ'אט, לא אליי** |

## 2 · סודות

**Supabase → Edge Functions → Secrets:**
`VAPID_PUBLIC` · `VAPID_PRIVATE` · `VAPID_SUBJECT` = `mailto:admin@800-plus.com` ·
`PUSH_TRIGGER_SECRET` = מחרוזת אקראית שתמציא

**GitHub → Settings → Secrets:**
`PUSH_TRIGGER_SECRET` = **אותו ערך בדיוק** · `PUSH_TEST_EMAIL` = הכתובת שתקבל את הבדיקה

⛔ הכתובת בסוד ולא בקובץ. הריפו ציבורי, וכתובות כבר דלפו ממנו פעם. יש שער בבדיקות
שנופל אם כתובת מייל תיכנס לקובץ המפעיל.

## 3 · פריסה

```bash
supabase functions deploy send-push
```

⚠ ה-README של `supabase/` מתעד פריסה של `billing-webhook` בלבד. הפונקציה הזאת
כנראה מעולם לא נפרסה, ולכן הצעד הזה אינו טכני-בלבד אלא ממש חסר.

וגם: **`config.js` המעודכן חייב לעלות לאתר החי.** בלי המפתח הפומבי באתר, הדפדפן
לא יוצר מנוי, ואין למי לשלוח.

## 4 · המנוי — ⛔ זה קורה במכשיר שלך, לא כאן

**אני לא יכול ליצור מנוי Push עבורך.** מנוי נוצר רק כשהדפדפן במכשיר מבקש אותו
ומקבל אישור מהמשתמש.

1. לפתוח את **האפליקציה המותקנת** במכשיר. ⚠ באייפון **חייבת להיות מותקנת למסך
   הבית** — מלשונית Safari ה-API זורק, ו-`askable()` בקוד כבר חוסם את זה.
2. לאשר התראות.
3. לוודא שנוצרה שורה: Supabase → Table Editor → `push_sub`.

## 5 · הבדיקה

Actions → **התראת תרגול יומית** → Run workflow:

| | |
|---|---|
`audience` | `me` |
`dry_run` | **false** |

הריצה נופלת בקול אם משהו חסר — סוד לא מוגדר, כתובת בלי משתמש, משתמש בלי מנוי, או
אפס התראות שנשלחו. ⭐ **"200 עם sent=0" נחשב כישלון**, כי זו בדיוק צורת התקלה
שנמשכת חודשים בלי שאף אחד שם לב.

## 6 · פתיחה לכולם

אחרי שההתראה הגיעה למכשיר:

**Settings → Variables → `PUSH_AUDIENCE` = `all`**

זו הפעולה היחידה שפותחת את זה לכל המשתמשים, והיא הפיכה בשנייה. עד אז — גם הריצה
המתוזמנת שולחת רק לכתובת הבדיקה.

## ⚠ מה שיישאר נכון גם אחרי שהכול יעבוד

1. **iOS מתעלם מכפתורי פעולה בהתראה.** אנדרואיד מציג אותם. לכן הדפוס הוא הודעה
   אחת + לחיצה שפותחת את האפליקציה, ולא תרגול בתוך ההתראה.
2. **אין תזמון מהמכשיר.** `Notification Triggers API` נזנח, ולכן המפעיל בצד השרת
   הוא לא פתרון זמני אלא הדרך היחידה.
3. **cron של גיטהאב אינו מכיר שעון קיץ.** 16:00 UTC = 19:00 בקיץ, 18:00 בחורף.
4. ⛔ **מדיניות פרטיות.** מנוי Push הוא מידע אישי חדש שנאסף. זה הפער הרגולטורי
   שכבר פתוח, ופתיחת ההתראות לכלל המשתמשים מרחיבה אותו.
